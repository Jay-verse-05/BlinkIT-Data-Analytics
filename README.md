
# BlinkIT Grocery Data Analysis 📊

## 📌 Project Overview
This project focuses on analyzing BlinkIT grocery data using Python to uncover meaningful business insights, customer purchasing patterns, sales performance, and outlet-level trends.

The analysis is performed using Jupyter Notebook (`BlinkIT.ipynb`) with Exploratory Data Analysis (EDA) and data visualization techniques.

## 🎯 Objectives
- Analyze overall sales performance.
- Identify top-performing item categories.
- Understand customer purchasing behavior.
- Compare sales across different outlet types and locations.
- Analyze the impact of item attributes on sales.
- Generate actionable business insights.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash

```

**2. Navigate to the project directory**

```bash
cd BlinkIT-Data-Analysis
```

**3. Install required libraries**

```bash
pip install pandas numpy matplotlib seaborn openpyxl jupyter
```

**4. Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open `BlinkIT.ipynb` and run the cells.
